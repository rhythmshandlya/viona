# Animation Philosophy

Create **visual narratives**, not decorated slides.

## Three Laws

### 1. Continuous Motion
Animation throughout duration, not just entrance effects.

- ❌ Elements spring in, then sit static
- ✅ Elements enter, DEMONSTRATE, then transition

### 2. Conceptual, Not Literal
Show WHY and HOW, not just WHAT.

| Topic | ❌ Literal | ✅ Conceptual |
|-------|-----------|---------------|
| "Binary tree is slow" | Static tree | Search path growing, O(n) climbing |
| "Caching improves speed" | Cache icon | Request hits cache (instant) vs DB trip (long) |
| "Memory leak" | RAM icon | Container filling, overflowing |
| "Race condition" | Two threads | Two cars colliding at intersection |

### 3. Zero Text Overlays
Subtitles handle text. Your job is PURE VISUAL STORYTELLING.

- ❌ Animated text "Step 1: Configure"
- ❌ Labels floating over diagrams
- ✅ Visual metaphors needing no explanation
- **Exception:** Single numbers for data viz (e.g., "85%")

## The Test

"If I mute the audio, does the animation TEACH the concept?"

No → Decoration
Yes → Meaningful animation
