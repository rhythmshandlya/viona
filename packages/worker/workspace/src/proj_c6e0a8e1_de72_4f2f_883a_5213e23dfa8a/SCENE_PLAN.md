# SCENE PLAN: Skills vs MCP Explainer

## CONTENT ANALYSIS

**Core Concept:** Explaining the fundamental difference between Skills (lazy-loaded instruction folders) and MCP servers (pre-loaded tool repositories) in AI systems.

**Key Insight:** Skills prioritize efficiency through on-demand loading, while MCP prioritizes immediate access through upfront loading - each serving different use cases.

**Target Emotion:** Understanding and clarity about when to use each approach.
